The Elon framework: five rules for getting things done

The investment question

A first-principles sequence: question requirements, remove what is unnecessary, simplify, accelerate, then automate.

Good decisions often improve when unnecessary work is removed before a process is accelerated. Starting with first principles can reveal assumptions that were accepted only because they were already part of the workflow.

How to use this idea

Applied to investing, this means choosing the few questions that genuinely change an outcome, then seeking evidence for and against them instead of adding complexity for its own sake.

The goal of this written brief is to make the central question easier to revisit and test over time. The accompanying video contains the complete discussion, examples and supporting context.
